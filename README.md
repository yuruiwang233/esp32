# ESP32-S3 BLE 智能遥控小车

这是一个基于 **ESP32-S3** 主控和 **TB6612FNG** 电机驱动的低功耗蓝牙（BLE）遥控小车项目。系统内置前端 Web 控制界面，支持通过**手机/网页按键**、**键盘**以及**游戏手柄（Gamepad API）**进行双轮差速控制。

---

## 🌟 项目特性

- **硬件双核控制**：基于 ESP32-S3，采用 TB6612FNG 双路直流电机驱动芯片。
- **Web 蓝牙直连**：基于 Web Bluetooth API，使用 Chrome / Edge 浏览器无需安装 APP 即可直接连接小车。
- **多种遥控模式**：
  - **手机 / Web 控件**：点击屏幕按钮控制前进、后退、左转、右转、停止。
  - **键盘快捷键**：支持 `W / A / S / D`、方向键及空格键控制。
  - **手柄差速遥控**：基于 Gamepad API，支持 Xbox 等标准手柄。
    - **左摇杆完全操控**：Y 轴控制油门，X 轴控制差速转向。
    - **LT 扳机 + 右摇杆**：LT 线性油门，右摇杆实现独立差速转向。
- **自动化安全保护**：BLE 断开连接或按键松开时自动紧急停止小车，防止跑飞。
- **兼容 Arduino ESP32 SDK v2 & v3**：固件内做了 LEDC PWM 的跨版本兼容处理。

## 🛠️ 硬件接线指南

### TB6612FNG 驱动与 ESP32-S3 接线

| TB6612FNG 引脚 | ESP32-S3 引脚 | 说明 |
| :--- | :--- | :--- |
| **AIN1** | GPIO 1 | 左轮方向控制 1 |
| **AIN2** | GPIO 2 | 左轮方向控制 2 |
| **PWMA** | GPIO 4 | 左轮 PWM 调速 |
| **BIN1** | GPIO 12 | 右轮方向控制 1 |
| **BIN2** | GPIO 13 | 右轮方向控制 2 |
| **PWMB** | GPIO 6 | 右轮 PWM 调速 |
| **STBY** | 3.3V / GPIO | 保持高电平使能（若接 GPIO 可在代码中修改 `TB6612_STBY`） |
| **VM** | 外接电机电源 (4.5V-13.5V) | 电机供电 |
| **VCC** | 3.3V | 芯片逻辑电源 |
| **GND** | GND | 共地 |

## 📡 蓝牙通讯协议

- **蓝牙设备名**：`ESP32S3-CAR`
- **服务 UUID**：`6e400001-b5a3-f393-e0a9-e50e24dcca9e`
- **特征 UUID (RX)**：`6e400002-b5a3-f393-e0a9-e50e24dcca9e`

### 指令集

| 指令格式 | 示例 | 说明 |
| :--- | :--- | :--- |
| `F` | `F` | 前进 |
| `B` | `B` | 后退 |
| `L` | `L` | 原地/单侧左转 |
| `R` | `R` | 原地/单侧右转 |
| `S` | `S` | 停止 |
| `V<速度>` | `V180` | 设置默认电机基础速度（范围：`0~255`） |
| `D<左轮>,<右轮>` | `D128,200` | 差速控制命令，左右轮速度范围 `-255 ~ 255`（正数前进，负数后退，0停止） |

## 🚀 快速开始

### 1. 烧录 ESP32-S3 固件
1. 安装 [Arduino IDE](https://www.arduino.cc/en/software) 并配置 ESP32 开发板支持库。
2. 打开项目中的固件源码 `esp32s3_ble_car.ino`。
3. 开发板选择 `ESP32S3 Dev Module`，编译并烧录至 ESP32-S3。
4. 打开串口监视器（波特率 `115200`），确认看到 `ESP32-S3 BLE car ready`。

### 2. 运行前端控制台
由于 Web Bluetooth 规范限制，前端页面必须通过 **HTTPS** 或 **localhost** 环境打开：

1. 使用静态服务器（如 VS Code Live Server 或在前端目录下运行 `python -m http.server 8000`）。
2. 使用 **Chrome** 或 **Edge** 浏览器访问 `http://localhost:8000`。
3. 点击 **“连接蓝牙”**，在弹出的设备列表中选择 `ESP32S3-CAR` 并配对。
4. 连接成功后，即可通过页面按键、键盘或切换至“手柄遥控”模式进行操控！
